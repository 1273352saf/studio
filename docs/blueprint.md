# **App Name**: NewsFlash

## Core Features:

- Article List Display: Display a list of news articles with titles, brief summaries, and source information. Each article should be a clickable link to the full article on the original news source's website.
- Real-time Search: Implement a simple search bar to allow users to filter news articles by keywords. The search should dynamically update the article list as the user types.
- Sentiment Analysis: Implement a tool that analyzes the sentiment of the articles and displays an aggregate sentiment score (positive, negative, or neutral) for each article. The sentiment tool will reason about context to improve accuracy.

## Style Guidelines:

- Primary color: Use a clean white or light gray background for readability.
- Secondary color: A professional blue or gray for headings and important text elements.
- Accent: Use a vibrant teal (#008080) for interactive elements like links and search button highlights.
- Use a card-based layout for displaying news articles. Each card should contain the title, a brief summary, and the source of the article.
- Use simple, recognizable icons for categories or tags associated with each news article.
- Subtle hover effects on article cards to indicate they are clickable.
